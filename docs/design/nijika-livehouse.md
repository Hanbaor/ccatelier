# Live House · 互动现场

在已确认的极简大图版上新增独立演出层，从首页或节奏实验室的「进入现场」打开。不是把已有步进编曲器换个名字。

- 四个立体鼓面支持触摸、点击和 A / S / D / F，快捷键只在现场对话框内生效，输入控件与组合键不抢占。
- 34.286 秒原创合成演出：112 BPM、16 小节，入场、渐进、高潮、尾奏。鼓、贝斯、暖和弦由 Web Audio 实时合成，没有网络音源，也不是结束乐队歌曲。
- 追光、空间地面、扩散声环与鼓面反馈随演奏联动；音频开启时展示实际采样波形。全局灯光反馈限频 400ms，低对比柔和过渡，没有频闪。
- 打开和播放均默认静音，只有明确点击「开启声音」才创建 AudioContext。默认音量 30%，滑杆上限 60%，压缩器保护输出；设备实际响度仍取决于系统音量。
- 停止、关闭、切后台或离开页面会停止音频和计时；结束后可自由即兴。退出恢复入口焦点和页面位置，原生 dialog 保持焦点边界，Escape 退出。
- 尊重系统 / 全站减少动态，也可单独切换静态灯光；无 Web Audio 仍可使用静音舞台，无 Canvas 仍保留背景和鼓面控件。
- 演出 JS 点击入口才动态加载；复用现有 WebP。Canvas 上限宽 1440、约 30 fps，关闭或后台不绘制。

验证：npm test；npm run test:fixtures。实际分支预览需核对桌面、窄屏、静音开场、允许音频、停止/退出/重新打开、键盘及减少动态。

## 录下灵感（2026-10-09）

折叠录音条把实时鼓面与现有排练室相连，不复制六轨音序器。录制只接收四个鼓面的用户输入，不访问麦克风，不抓取现场演出，不上传节奏。

- 显式点击录制；四拍预备后录 2 / 4 小节，40–220 BPM，最近十六分格量化。同一鼓面同一格合并，尾端不回卷，预备拍和到点后的输入不计入。
- 鼓面在 pointerdown 接触时记时；键盘 A / S / D / F 与无障碍按钮激活可用，忽略重复按键与合成的指针 click，支持多指同时敲击。
- 逐格小条提供低动态进度与命中反馈。音频始终由独立声音开关开启；录制与回放不会自行启用音频。自然完成后保留已经开启的音频，取消、停止、关闭、后台、离页立即停止。
- 先回放，再明确「送去排练」。每段使用独立本机录音键；最多 12 段有效录音，不覆盖旧录音、JSON 导入或音序器项目。损坏槽位不占有效容量，也不会被静默删除。
- 新页面按录音编号读取并严格校验；同页交接保留原导入谱面并更新 URL。排练室可重新选择录音、调整速度、循环指定小节及导出；移除本机录音需要显式确认。
- 本机存储拒绝或配额不足时留在现场，保留回放和 JSON 下载。页面内完成但未送出的录音明确标注尚未保存；取消重录仍保留上一段完成的节奏。
- 关闭录音条、开启原演出、关闭现场、切后台或离页会取消未完成录制 / 回放；没有自动恢复或后台工作。

自动验证：`npm test` 158 项通过；`npm run test:fixtures` 通过，包括 `/lab/` 路径。覆盖量化边界、重复击打、容量 / 配额 / 损坏存储、count-in、回放、取消、触摸与键盘重复、音频 opt-in、同页导入保留、URL 交接、移除确认、减少动态。浏览器桌面 / 窄屏视觉与触控体验须在发布前另外核对。

## 可渐进增强的真实鼓组（本地候选，尚未发布）

现有插画、标题、按钮位置、键盘标签、录音与声音入口全部保留。新增 WebGL2 层只绘制鼓皮、漆面鼓腔、金属鼓圈、张力螺杆及薄铜镲；画布不接收指针，也不进入无障碍树。点击仍由原生按钮处理，视觉层不参与录音时钟、音频或谱面交接。

- 打开现场后才异步读取小型适配器；确认 WebGL2 可用后，再读取同源固定版本 Three.js。页面初始模块图不增加 Three.js，没有外部 CDN、模型或贴图请求。
- 第一次渲染成功后才隐藏 CSS 鼓皮。WebGL 被禁用、离线、模块失败、着色器失败、绘制失败与上下文丢失均回退到原有 CSS 鼓组，原生按键继续可用。
- 固定正交相机按实际 CSS 变换矩阵与父元素透视计算鼓面椭圆，而非把旋转后的矩形包围盒当作鼓面；独立深度缩放保留窄屏较高的原生目标。保留原生悬停变换，悬停及 transform 过渡结束时重新测量，折叠录音条和窗口尺寸变化后刷新布局。标签及键盘焦点始终位于画布上方。
- 鼓皮击打位移不超过约 2px，镲片轻微摆动上限 2°，700ms 内回到静止。没有连续自动 GPU 动画；只在有效击打或指针光线响应时请求短暂动画，最高 30fps。全站 / 系统减少动态时只进行必要的静态绘制。
- 页面隐藏立即取消 GPU 帧；异步载入若在隐藏期间完成，等页面重新可见才首绘。关闭与离页中止待加载工作，取消帧、移除观察器、释放几何体 / 材质 / 纹理 / 渲染器及上下文。过期载入不能装入新的现场。
- 上下文丢失时立刻恢复 CSS 鼓皮；恢复事件仅对仍然有效的现场尝试静态重绘。失败继续使用 CSS，不自动循环重试。
- 画布 DPR 上限桌面 1.5、窄屏 1.25，缓冲宽度最多 1024px、总像素不超过 100 万。共享几何体和实例化螺杆，无阴影贴图、后处理或物理模拟。

### 依赖与重现

Three.js 固定为 `0.186.0`（MIT），官方来源为 [r186](https://github.com/mrdoob/three.js/releases/tag/r186) / npm 官方 `three` 包。`tools/build-livehouse-three.cjs` 使用 esbuild `0.28.1` 只导出所需的 WebGL、几何体及材质类；校验三个官方输入文件的 SHA-256，生成 `source/atelier/vendor/three/0.186.0/` 下的本地模块、LICENSE 和 provenance.json。

当前构建：543,774 字节 minified / 136,624 字节 gzip；这只是本机构建体积，不是网络实测或设备性能结论。上限分别为 650,000 / 180,000 字节。适配器与纯数学策略合计 15,365 字节。原始官方 WebGL module + core 为 2,120,885 字节，因此不直接随站点发送。

重现方式：使用受信任的官方 `three@0.186.0` 包与 `esbuild@0.28.1`，运行 `node tools/build-livehouse-three.cjs`；独立已校验包可通过 `--package /absolute/path/to/three` 指定。构建脚本不会下载软件。默认包定位使用公开入口 `require.resolve('three')`，避免访问未导出的 `three/package.json`。恢复检查已在隔离官方包目录执行不带 `--package` 的重建，产物 SHA-256 与随站文件完全一致。开发依赖已精确固定为 `three@0.186.0` 与 `esbuild@0.28.1`，锁文件同步；实际项目中运行默认重建命令也已成功，产物及 provenance 与隔离重建完全一致。

离线文章清单只扫描 `atelier/js`、`atelier/css`、`atelier/fonts`，所以 `atelier/vendor/three` 不会增加每篇离线文章的资源包。适配器可被保存，三维依赖不可用时原 CSS 舞台继续工作。未改动 service worker 的事务保存逻辑。
