# Live House · 互动现场

在已确认的极简大图版上新增独立演出层，从首页或节奏实验室的「进入现场」打开。不是把已有步进编曲器换个名字。

- 四个立体鼓面支持触摸、点击和 A / S / D / F，快捷键只在现场对话框内生效，输入控件与组合键不抢占。
- 34.286 秒原创合成演出：112 BPM、16 小节，入场、渐进、高潮、尾奏。鼓、贝斯、暖和弦由 Web Audio 实时合成，没有网络音源，也不是结束乐队歌曲。
- 追光、空间地面、扩散声环与鼓面反馈随演奏联动；音频开启时展示实际采样波形。全局灯光反馈限频 400ms，低对比柔和过渡，没有频闪。
- 打开和播放均默认静音，只有明确点击「开启声音」才创建 AudioContext。默认音量 30%，滑杆上限 60%，压缩器保护输出；设备实际响度仍取决于系统音量。
- 停止、关闭、切后台或离开页面会停止音频和计时；结束后可自由即兴。退出恢复入口焦点和页面位置，原生 dialog 保持焦点边界，Escape 退出。
- 尊重系统 / 全站减少动态，也可单独切换静态灯光；无 Web Audio 仍可使用静音舞台，无 Canvas 仍保留背景和鼓面控件。
- 演出 JS 点击入口才动态加载；复用现有 WebP。Canvas 上限宽 1440、约 30 fps，关闭或后台不绘制。

验证：npm test；npm run test:fixtures。实际分支预览需核对桌面、窄屏、静音开场、允许音频、停止/退出/重新打开、键盘及减少动态。
