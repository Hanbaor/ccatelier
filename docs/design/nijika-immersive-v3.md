# Nijika：沉浸式第三版

根据预览反馈，这轮删除大量装饰性文案，保留实际内容和功能。

- 首页只有一组品牌字、一句介绍、一幅占主导的舞台画面与探索入口。删除英文标牌、卷号、图章文案、重复栏目表和口号。
- 导航保留三个直接入口，其他目的地收进菜单；手机使用独立竖幅插画，避免从宽图裁掉脸和手。
- 创作室直接进入图像栏目与真实文章；笔记压缩开头，把搜索、筛选和文章列表前移。
- 六个栏目删除约77%的页面说明文字，保留个人事实、真实文章、按钮标签、留言隐私提示及所有后台功能。
- 增加四张新插画：夜场演奏、音乐电子工作台、持鼓槌竖幅肖像、屋顶城市全景。全部采用高质量WebP和960w版本。
- 动效集中在开场揭幕、品牌字入场、图片轻微悬停和一次性滚动显现；不劫持滚动，遵循减少动态与原有动效开关。
- 使用SVG箭头和装饰符号，避免字体缺字；修正具有固有高度的插画在缩放时变成过高肖像的问题。

使用 `npm test`、`npm run test:fixtures` 和 `git diff --check` 验证代码，随后在 nijika-dot 的精确版本预览中检查桌面、窄屏、日夜和主要操作。本文不代替实际浏览器验收记录。
