# 原创鼓谱排练室与场景导览

## 排练室

路径 `/studio/practice/`，从节奏实验室进入。首页仍保持极简大图，复杂练习工具只出现在专属页面。

- 三段本站原创示范：八分基本律动、切分节奏、通鼓过门，不是结束乐队歌曲的转录。
- SVG 打击乐节奏图谱：五线定位 + 十六分网格，逐格游标，小节点击选起点。它是节奏练习视图，不声称复现专业出版刻谱的完整时值、休止符、连音等记谱规则。
- 明确点「开始跟练」后才创建音频；先数四拍，再播放。40–220 BPM、指定小节循环、节拍器 / 示范鼓声独立开关、默认低音量。
- 结构/速度调整暂停，避免连续拖动时产生重叠演奏；停止、切后台和离开页立即关闭音频并清理任务。播放不自动滚动页面。
- JSON 导出及严格校验的本机导入，最多 64 小节；不执行文本或 HTML、不请求网络、不上传文件。
- 官方乐谱抽屉仅链接 Yamaha 出版商品，不复制付费谱面、封面或预览。鼓谱集收录曲名与总谱集页面在 2026-10-09 核实：
  - https://sheetmusic.jp.yamaha.com/products/4947817310204
  - https://sheetmusic.jp.yamaha.com/products/4947817305804

## 场景导览

保留九条原生链接。鼠标悬停 / 键盘聚焦时切换对应插画，图片就绪后再交叉渐变；手机首次点击直接导航。图片采用 contain 保留脸、手与环境；异步过期请求不会覆盖新场景，失败保持旧图。遵循全站 / 系统减少动态，没有常驻动画循环或音频。

验证：`npm test`、`npm run test:fixtures`，以及正式分支预览的桌面 / 窄屏交互与视觉检查。

## 跟拍挑战

排练室内的可收起面板，不增加首页入口或自动声音。选好原创练习、自己的录音 / 有权使用的本机谱面与小节后，明确点「开始挑战」；展开面板本身不发声。沿用当前速度和四拍预备，同一个 transport origin 同时驱动谱面、节拍器、挑战网格和输入判定，没有另起一条计时循环。输入使用同时间域的事件发生时间，避免主线程稍晚处理事件时凭空增加延迟；不兼容的时间戳安全回退。挑战只走一遍选区，示范鼓声暂停，结束后保留原跟练开关设置。

- 固定四行十六分音符网格，不滚落、不追光闪烁；触屏在按下时判定，A / S / D / F 仅在挑战活动且没有编辑文本 / 对话框时生效。鼓垫保留原生按钮与键盘辅助操作。鼓垫敲击不触发全站点击烟花。
- 同声部就近匹配尚未接住的目标。不同声部可同时命中；每个目标只能命中一次；同鼓 25ms 内的重复事件忽略，不吞掉最快 220 BPM 的正常十六分节奏。键盘重复 / 未释放按键、重复触点与兼容 click 均有单独保护。
- ±120ms 接住，±45ms 记合拍；跟拍率为「接住数 ÷（目标数 + 额外敲击）」四舍五入。零力度不算目标，全休止选区不启动挑战。保留休止小节与尾部时长，并为最后一个音符留足迟到窗口。设备音频和输入延迟仍存在，不做硬件延迟校准或精准计量承诺。
- 同一准确节奏、选区与 BPM 的最佳跟拍率存于独立本机键 `cc-practice-best-v1`；最多 12 项、序列化大小受限。既有录音和音序工程不改动，禁止成绩上传与遥测。存储阻止 / 损坏 / 配额满时照常完成，并明确提示未保存。
- 停止、收起、切后台、失去窗口焦点、打开对话框或 Live House、切换速度 / 选区、离页均撤销当前挑战，关闭音频并清理输入状态；未完成的成绩不保存。挑战与跟练共享一个音频上下文；节奏实验室通过明确的播放事件互斥。

自动覆盖：同时音符、密集音符的重复事件、窗口边界、尾音迟到、休止、原谱 / 原速匹配、限制存储、音频启动竞态、各种取消路径、连续重试以及全部既有导入生命周期回归。运行 `npm test` 与 `npm run test:fixtures`。
