# Nijika / Volume 02

本轮直接重构首页、创作室、笔记、项目、研究、生活、关于、后台小屋和留言的页面结构，并更新节奏实验室主视觉。文章正文、来源和原有交互继续保留。

## 设计与阅读

- 首次访问默认日光纸色；已经选择过夜场的浏览器继续使用夜场。
- 首页改为编辑式品牌版面、独立插画画框和五个可直接访问的栏目入口。
- 创作室使用演奏场景与票根，再展开不同的栏目画面，避免同一张头像反复充当整页背景。
- 笔记先展示三篇真实的最近手记，再进入可筛选、全文检索的目录。默认使用更紧凑的曲目表，唱片架和星图仍可切换。
- 所有新图使用 WebP 与 960w 响应式版本，不改变生成原图的内容。六张完整 WebP 合计约 1.96 MB；原 PNG 仍单独保留，不重复打包到网页。

## 新插画

六张均为 AI 创作的虹夏主题同人插画，不是官方剧照。人物与视觉风格保持连贯，场景分别对应实际页面用途。

| 文件 | 原始尺寸 | 用途 |
| --- | --- | --- |
| hero.webp | 1672 × 941 | 日光排练室 / 首页 |
| stage.webp | 1672 × 941 | 鼓手演奏 / 创作室、节奏实验室 |
| notes.webp | 1536 × 1024 | 窗边笔记桌 / 笔记、关于 |
| research.webp | 1536 × 1024 | 研究手稿与星图 / 研究 |
| life.webp | 1536 × 1024 | 雨后下北泽 / 生活 |
| lounge.webp | 1536 × 1024 | 后台喝茶与唱片 / 小屋、留言 |

网页资源位于 `source/atelier/images/v2/`。源图精绘保持完整；不同版面只通过 CSS 设置裁切和对齐。后续更换主视觉可更新 `_config.redefine.yml`；响应式 helper 只对已提供小尺寸版本的 v2 图生效。

## 验证

执行 `npm test`、`npm run test:fixtures` 和 `git diff --check`。新增测试覆盖全新页面结构、导航、不同页面使用独立画面、图片路径与尺寸、日光默认值/已保存夜场、紧凑目录与原浏览方式、六个栏目的真实内容及后台原有功能。

布局验收通过 Cloudflare 为 `nijika-dot` 自动生成的精确版本预览进行。只有经实际浏览器验证的视口和流程会计入最终验收说明；本地静态测试不替代视觉验收。
