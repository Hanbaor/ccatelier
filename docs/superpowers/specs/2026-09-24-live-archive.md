# Live Archive / 深度升级

## 目标
用户要求全面升级为具有大量实质能力的虹夏博客，尤其指出现有封面/人物图普通、notes 平庸、文章阅读混乱。四张参考截图已逐张检查。保留109篇真实文章、Hexo/Redefine、已有评论服务和简单小功能，不伪造内容/AI摘要/远程同步。

## 设计
统一暖金、深墨、朱红，加入细密坐标、导轨、唱片编号、纸质注释，不使用荧光黑客界面。入口用新的宽屏原画和景深/光场。笔记区采用 Live Archive：小型杂志封面、内容筛选面板、唱片档案与主题星图共享同一组数据。阅读页采用 Reading Studio：紧凑标题、左侧章节轨道、居中正文、右侧可收起工作台；清除渲染时的重复文章标题，保留 Markdown 原文。

## 完整交付与证据要求
0. 整站特效引擎：GPU舞台追光/星尘/涟漪、弹性视差与磁吸交互、统一跨页面转场、调光台、音频驱动频谱和灯光；功能之间有真实数据联动。后台/隐藏页停帧，阅读区降噪，减少动态效果/低能力设备优雅降级。用户再次明确不是只强化笔记，整站的玩具、特效和功能都应具有技术深度并符合主题。
1. 新主视觉：检索公开艺术来源，生成/选择适合布局的原创资产；检查面部、肢体、裁切、手机效果，记录来源，不冒充官方作品。
2. 高级笔记浏览：全109篇内容索引、正文检索、类型/主题/阅读时长筛选、排序、可分享查询URL、网格/列表切换、清空/空状态、键盘可操作。
3. 主题星图：由真实文章与标签生成关联，力导向布局、拖动、缩放、选择节点详情、相关路径、聚焦与重置；减少动态效果时静止，无Canvas时有列表替代。
4. 阅读队列：添加/移除、调整顺序、继续下一篇、进度状态、数据校验、导入/导出，持久化受限时说明。
5. 阅读工作台：新正文排版与章节轨道、活动章节、文内查找及匹配跳转、可复制章节链接、字号/行宽/行高、专注模式、跨文相关推荐。
6. 个人批注：文本选区摘录、带上下文锚点、个人笔记、定位原文、IndexedDB保存、导出/导入、删除；正文变化无法定位时明确告知。禁止将用户笔记作为HTML插入。
7. 代码工作台：专用阅读对话框、行号、行焦点、换行、复制、源码下载；不在页面执行代码。
8. 阅读辅助：浏览器语音朗读及语速/暂停/停止、可用性提示、关闭/离开停止；阅读完成标记与个人阅读轨迹。
9. 离线书架：用户主动缓存选定文章与本站必要资源、容量与离线状态、移除/更新、离线可读；不缓存API/评论/管理页/秘密，支持子目录部署。
10. 音乐实验室：多轨音序、16/32步、音色参数、音量/声像/静音/独奏、swing、预设、项目保存/导入导出、撤销重做、波形/频谱、OfflineAudioContext导出WAV；真实音频时钟排程，禁止自动播放，关闭/后台停止。
11. 所有新功能有清晰入口、原生链接回退、加载与错误状态；桌面1440/平板820/手机390视口、键盘、减少动态效果验收。
12. 服务、文章、既有功能无回归；自动测试涵盖搜索过滤、关联、锚点/导入校验、队列、音频计划/WAV、离线边界；真实浏览器走完整流程，独立审查后修复。

## 架构
构建时生成 rich archive JSON 与 related helper；浏览器 ES module + Web Worker 搜索，Canvas 图谱；IndexedDB保存批注/项目，localStorage保留轻量偏好；Service Worker仅在用户主动离线保存时注册。音频使用Web Audio，无外部账号/API密钥。新样式按 archive/reader/studio 分文件，替换受影响旧规则，避免不断叠加冲突。

## 边界
本地源码与可运行预览，本轮不发布线上。不修改原文，不把规则关联伪称语义AI。部署需要的D1沿用上轮边界。开发不在Wrangler运行期间删除public，以免重现WSL目录锁。
