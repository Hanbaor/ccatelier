## <strong>set</strong>

<a id="csdn-section-2"></a>

### <strong>1.set的简单介绍</strong>

set的中文翻译为“集合”，实际上，c++中的set的确实现了集合的功用，与vector不同的是，set是一种<strong>关联容器</strong>。

在set容器中，元素保有其<strong>互异性</strong>，其中的每个元素都是互不相同的。（这里的互不相同是指，假如set容器中已经包含了一个数字a，那么无论之后再向set中加入多少次a，set中仍然只会有这一个元素a，不会出现很多a的情况）在某种程度上。这也意味着set具有<strong>去重</strong>功能

我们所熟知的“集合”，还有一个特性：无序性。而set中的元素并不是无序的，而是<strong>升序</strong>排列的，在一个数据插入set时，set能够根据数据的值<strong>自动</strong>进行排序。

而且set的插入删除效率比用其他序列容器高。

之所以set容器能够自动有序，快速添加、删除，是由他的内部实现的：set容器的内部采用了一种<strong>非常高效的平衡检索二叉树</strong>：<strong>红黑树。</strong>关于红黑树，我只能说介于我现在的水平与时间，难以完全展开解释，而且红黑树在<strong>数据结构</strong>中也是比较复杂高深的，我这里就不做过多介绍，感兴趣的朋友可以自行了解~。

#### 2.set的常用函数

首先要介绍的就是：

<strong>st.insert( )</strong>   在st中<strong>插入</strong>元素。

<strong>st.begin()    </strong>返回指向第一个元素的迭代器.

<strong>st.end()      </strong>返回指向最后一个元素下一个位置（<strong>注意不是最后一个元素</strong>）的迭代器.

有了这三个函数，我们就可以实现set容器的一些基本功能。

```cpp
#include<iostream>
#include<set>
using namespace std;

int main()
{
	set<int> st;
	
	st.insert(4);//将4插入st中，
	int n;
	for(int i=1;i<5;i++)//下面我们利用循环来插入多个数。如1，2，3，4 
	{
		cin>>n;
		st.insert(n); 
	 } 
	for(auto it=st.begin();it!=st.end();it++)//set容器的遍历 
	{
		cout<<*it<<" ";
	}
	//最后的输出为1 2 3 4，而不是4 1 2 3 4，可见set容器相同的元素只会储存一次。 
	return 0;
 }
```

上面的代码中，我们使用<strong>auto</strong>关键字定义的<strong>迭代器</strong>it，当然我们也可以用

<strong>set&lt;int&gt; ::iterator it=st.begin();</strong>的方式来定义一个迭代器<strong>。</strong>

---

<strong>st.find(value)   </strong>返回set中值为value的元素的迭代器。

```cpp
#include<iostream>
#include<set>
using namespace std;

int main()
{
	set<int> st;
	
	st.insert(4);
	int n;
	for(int i=1;i<5;i++)//1 2 3 4
	{
		cin>>n;
		st.insert(n); 
	 } 
	 auto it=st.begin();
	 it=st.find(2);
	for(;it!=st.end();it++)
	{
		cout<<*it<<" ";
	}//输出结果为2 3 4
	return 0;
 }
```

<strong>st.erase(it)</strong>    删除一个元素，it为需要被删除的元素的迭代器。

<strong>st.erase(value)</strong>    删除值为value的元素。

<strong>st.erase(it1,it2)</strong>     it1,it2均为迭代器，删除[it1，it2)内的元素（注意前闭后开）；

在刚刚代码的基础上：

	for(auto it=st.begin();it!=st.end();it++)

<strong>st.count(value)</strong>    判断值为value的元素是否在容器中。

<strong>st.empty()</strong>    判断是否为空，若为空返回true。

<strong>st.clear()</strong>      清空set中所有元素。

<strong>st.size()    </strong>set中元素的个数。

```cpp
#include<iostream>
#include<set>
using namespace std;

int main()
{
	set<int> st;
	int n;
	for(int i=1;i<5;i++)//1 2 3 4
	{
		cin>>n;
		st.insert(n); 
	 } 
	 cout<<st.size()<<endl;//结果为4 
	 if(st.empty()) cout<<"容器为空"<<endl;
	 else cout<<"容器不为空"<<endl;
	 if(st.count(3))  cout<<"容器内有3"<<endl;
	 else cout<<"容器内没有3"<<endl;
	 //输出结果为：容器不为空 容器内有3 
	 st.clear();//清空数组再进行判断 
	 if(st.empty()) cout<<"容器为空"<<endl;
	 else cout<<"容器不为空"<<endl;
	 if(st.count(3))  cout<<"容器内有3"<<endl;
	 else cout<<"容器内没有3"<<endl;
	 //输出结果为：容器为空 容器内没有3	  
	return 0;
 }
```

<strong>lower\_bound(key\_value)</strong> ，返回<strong>第一个</strong>大于等于key\_value的定位器。

<strong>upper\_bound(key\_value)，</strong>返回<strong>第一个</strong>大于key\_value的定位器。

这两位也有其用法，在这里我不赘述，先举一个简单的例子，在下篇文章中我会以一道题来详细说明。

```cpp
#include <iostream>
#include <set>
using namespace std;
int main ()
{
    set<int> st;
    st.insert(3);
    st.insert(4);
    st.insert(5);
    cout<<*st.lower_bound(3)<<endl;//3
    cout<<*st.upper_bound(3)<<endl;//4
    return 0;
}
```

#### 3.set的并，交，差，对称差

<strong>使用以下函数均需要包含头文件#include &lt;algorithm&gt;</strong>

`set_intersection`（取集合交集）

`set_union`（取集合并集）

`set_difference`（取集合差集）

`set_symmetric_difference`（取集合对称差集）

并不是只有<strong>set</strong>容器可以使用这四个函数，但两个集合必须是<strong>有序序列。</strong>

<strong>使用方法：（四个函数使用方法相似，这里以取并集为例）</strong>

`1.set_union(A.begin(),A.end(),B.begin(),B.end(),inserter(C1,C1.end()));`

将a的第一项至最后一项与b的第一项至最后一项取交集，并将结果储存在c1中。

或：前四项不变，<strong>inserter(C1,C1.end())</strong> 改为<strong>ostream\_iterator&lt;int&gt;(cout," ")。</strong>其功能为直接输出其并集。

ostream\_iterator&lt;int&gt;(cout," ")是一个<strong>输出流迭代器，使用时需要头文件#include &lt;iterator&gt;</strong>

第一个参数是输出流std::out，第二个参数可以是字符串，也可以是字符串常量，他表示<strong>各个元素被输出时的分隔符。</strong>

下面来进行一个总结：

```cpp
#include <iostream>
#include <algorithm>
#include <set>
#include <iterator>
using namespace std;
int main(){
	set<int>A;
	set<int>B;
	set<int>C1;//存交集 
	set<int>C2;//存差集 
	set<int>C3;//存对称差集 
	int n;
	for(int i=0;i<4;i++){//输入集合A的元素1 2 3 4 
		cin>>n;
		A.insert(n);
	}
	for(int i=0;i<4;i++){//输入集合B的元素2 3 4 5
		cin>>n;
		B.insert(n);
	}
	cout<<endl; 
	
	cout<<"并集："<<endl; 
	set_union(A.begin(),A.end(),B.begin(),B.end(),ostream_iterator<int>(cout," "));//这里我们不存并集，直接输出。
	 
	set_intersection(A.begin(),A.end(),B.begin(),B.end(),inserter(C1,C1.end()));//之后我们采用先储存，再遍历的方式输出。 
	cout<<endl<<"交集："<<endl; 
	for(auto pos=C1.begin();pos!=C1.end();pos++){
		cout<<*pos<<" ";
    }
    
	set_difference(A.begin(),A.end(),B.begin(),B.end(),inserter(C2,C2.end()));
	cout<<endl<<"差集："<<endl; 
	for(auto pos=C2.begin();pos!=C2.end();pos++){
		cout<<*pos<<" ";
	} 
	
	 set_symmetric_difference(A.begin(),A.end(),B.begin(),B.end(),inserter(C3,C3.end()));
	cout<<endl<<"对称差集："<<endl;
	for(auto pos=C3.begin();pos!=C3.end();pos++){
		cout<<*pos<<" ";
	} 
	return 0;
}
```
